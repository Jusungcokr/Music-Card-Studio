# 음악 카드뉴스 스튜디오

좋아하는 곡 하나를 입력하면 **인스타그램·유튜브 쇼츠용 카드뉴스 3장**과 **캡션/제목/설명**을 만들어 주는 브라우저 스튜디오입니다.
서버 없이 정적 파일만으로 동작하고, 입력한 내용과 이미지는 브라우저 밖으로 나가지 않습니다.

## 쓰는 법

1. `index.html`을 열면 예시 곡이 채워진 상태로 시작합니다.
2. 맨 위 **곡 링크로 자동 채우기**에 유튜브·스포티파이·애플뮤직 링크를 붙여 넣으면 곡명·아티스트·앨범 커버가 한 번에 채워집니다. 링크가 없으면 **음원 검색**에 곡명이나 아티스트를 적고 결과에서 곡을 고르면 됩니다.
3. 왼쪽에서 곡 정보·커버·가사·감상평·태그·핸들을 고칩니다.
4. 오른쪽에서 비율(4:5 / 1:1 / 9:16)과 테마 4종을 고릅니다.
5. `PNG` 버튼으로 한 장씩, `3장 모두 저장` 또는 `ZIP으로 받기`로 한 번에 받습니다.
6. 인스타 캡션·쇼츠 제목·설명은 `복사` 버튼으로 클립보드에 담습니다.

## 기능

- **곡 링크 자동 채우기** — 링크를 붙여 넣으면 곡명·아티스트(+발매년도·장르)·앨범 커버가 채워짐
  - YouTube · YouTube Music (`watch?v=`, `youtu.be/`, `shorts/`) — noembed oEmbed로 제목·채널명, `i.ytimg.com` 썸네일(1280×720 → 480×360 순서로 시도)
  - Spotify (`open.spotify.com/track/…`) — Spotify oEmbed로 곡명·커버, 아티스트·발매년도는 같은 제목의 iTunes 검색 결과로 보정
  - Apple Music (`music.apple.com/…?i=…`) — iTunes Lookup API로 곡명·아티스트·발매년도·장르·600×600 커버
  - 멜론·지니·플로·벅스·바이브 등 CORS가 막힌 링크는 “브라우저 보안상 직접 불러올 수 없다”는 안내와 함께 검색·직접 입력으로 유도
- **음원 검색** — iTunes Search API(한국·미국 스토어를 함께 조회해 노래 우선)로 최대 5개 결과를 칩으로 보여 주고, 누르면 곡명·아티스트·발매년도·장르·600×600 커버가 채워짐
- **음악 등록 폼** — 곡명, 아티스트, 장르·발매년도(선택), 앨범 커버 드래그/선택 업로드(없으면 테마 색 그라데이션 + LP 그래픽 자동 생성), 대표 가사, 추천 이유, 무드/상황 태그(칩 선택 + 직접 입력, 최대 6개), `@핸들` 워터마크
- **예시 곡 3종** — 새벽 감성 R&B / 인디 록 / 시티팝 (누르면 폼 + 테마가 함께 채워짐)
- **내 곡 보관함** — `localStorage`에 최대 40곡 저장·불러오기·삭제 (커버는 900px JPEG로 축소 저장)
- **비율 3종** — 4:5 (1080×1350), 1:1 (1080×1080), 9:16 (1080×1920)
- **테마 4종** — 다크 바이닐, 매거진 화이트, 웜 필름, 네온 나이트
- **커버 색 반영** — 업로드한 커버에서 대표색을 뽑아 테마 강조색과 섞어 카드 전체 색을 맞춤
- **카드 3장** — ① 표지(커버·곡명·아티스트·태그·워터마크) ② 킬링 포인트(인용구 + 트랙 정보) ③ 큐레이션 노트(상황 태그·한 줄 감상·저장/공유 유도)
- **내보내기** — 카드별 PNG(1080px 원본), 3장 ZIP(JSZip, 실패 시 순차 다운로드)
- **문구 자동 생성** — 인스타 캡션 + 해시태그, 쇼츠 제목(100자 이내)/설명, 원클릭 복사

## 파일 구성

```
index.html            화면 구조
css/app.css           스타일 (390px 모바일 ~ 1560px 데스크톱)
js/data.js            테마·비율·태그·예시 데이터
js/lookup.js          곡 링크 해석(YouTube·Spotify·Apple Music) · iTunes 검색 · CORS 안전 이미지 로딩
js/color.js           커버 대표색 추출 · 테마 색 혼합
js/render.js          Canvas 카드 렌더러 (3장 × 4테마 × 3비율)
js/captions.js        인스타/쇼츠 문구 생성
js/app.js             상태·폼·보관함·다운로드·복사
js/jszip.min.js       ZIP 생성 (JSZip 3.10.1, 로컬 번들)
assets/fonts/         Pretendard 가변 폰트 (로컬 번들)
```

## 로컬에서 열기

정적 파일이라 바로 열어도 되지만, 폰트·다운로드를 확실히 쓰려면 로컬 서버를 권장합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 확인한 것 (헤드리스 Chromium)

- 카드 3장이 비율별 1080×1350 / 1080×1080 / 1080×1920으로 렌더링되고 빈 캔버스가 아님
- 예시 3종 클릭 시 폼·태그·테마가 채워짐, 테마 전환 시 캔버스 픽셀 변화
- 개별 PNG(1080×1350)와 ZIP(3장, 각 1080×1350) 다운로드 성공
- 인스타 캡션 복사 시 클립보드 내용 일치
- 보관함 저장 → 새로고침 후 유지 → 불러오기 → 삭제
- 1280px·390px 모두 가로 넘침 없음 (`scrollWidth == innerWidth`), 콘솔 오류 0
